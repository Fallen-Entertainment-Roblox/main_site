How to Host This Site on GitHub Pages

Step-by-step instructions to get this page online for free

1 Create a GitHub Repository

Go to github.com/new and create a new repository.

  • Name it youtube-creator-showcase (or any name you like).
  • Keep it set to Public.

2 Upload This File (`index.html`)

Save this generated HTML code locally as index.html, then push it to GitHub using Git terminal commands:

git init
git add index.html
git commit -m "Initial creator showcase landing page"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
git push -u origin main

3 Enable GitHub Pages

  1. In your GitHub repo, go to Settings → Pages (on the left sidebar).
  2. Under Branch, select main branch and click Save.
  3. Wait 1-2 minutes. Your live site URL will be displayed at top: https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/
